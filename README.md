# Leonida Trophy Guide — a gta6-trophy-guide-01 entry

An offline web app: the complete guide and tracker for the 55 PlayStation 5 trophies of Grand Theft Auto VI. Checklist saved in the browser, export and import, filters by kind, a spoiler setting, a roadmap to the platinum, and the missable trophies flagged — all built from the official trophy descriptions, with a guide in our own words for every trophy.

Built for the [make.fun bounty gta6-trophy-guide-01](https://make.fun/bounty/gta6-trophy-guide-01). `main.ts` (Node 22, standard library only) hands the app in: it copies `app/` and `screenshots/` to `/output` and writes `/output/dossier.json` with the vendored make.fun library.
